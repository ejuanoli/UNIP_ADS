Conecte o Supabase

Este site é estático e pode ir para o GitHub Pages. Os dados e o login ficam no seu projeto Supabase, protegidos por regras de acesso.

  1. Crie um projeto em supabase.com.
  2. No SQL Editor, execute o arquivo sql/schema.sql.
  3. Em Authentication → Providers, deixe só Email (login + senha). Desative Google, GitHub, telefone e Magic Link. Desative também “Confirm email”.
  4. Em Project Settings → API, copie a URL e a chave anon public.
  5. Cole os valores em js/config.js e recarregue a página.

Nunca use a chave service_role neste site. A segurança vem das políticas RLS do banco.

A demonstração roda neste navegador, sem banco. Você pode conectar o Supabase depois.
